# HAGHS v2.3.1 Changelog

All changes on the `dev` branch relative to `main` (v2.3.0).

## Bug Fixes

### Coordinator can no longer be killed by an unguarded sub-component (#103)

**Problem:** `_build_recommendations` and `_build_rec_flags` ran outside the
`_safe_calc` safety net. An exception in either of them propagated out of
`_async_update_data`, which can interrupt the Home Assistant Core
`DataUpdateCoordinator` refresh cycle. The sensor then silently stops
updating until a manual integration reload (reported: interval not
applied, updates stalled for hours with no log entries).

**Fix:** `_async_update_data` is now a total safety-net wrapper. Any
exception is logged with a full traceback; the last valid result is
returned so the sensor never loses its value, with a neutral fallback for
the very first update. The previous logic moved to
`_async_update_data_inner`, and the result-dict assembly was extracted
into `_build_result`. The `_neutral_result` fallback builds its dict
inline and never calls the potentially failing sub-components.

**Files changed:**
- `custom_components/haghs/coordinator.py` - total safety net around the
  update cycle, `_build_result` / `_neutral_result` helpers
- `tests/test_coordinator_resilience.py` - three regression tests (red
  before the fix): no-raise on recommendations/rec-flags failure, last
  result kept on failure

### Label service names in the docs and UI text corrected (#99)

**Problem:** The README automation example, the `ignore_labels` field
descriptions in `strings.json` / `translations/en.json` and the `_is_ignored`
docstring in `coordinator.py` referenced the services `label.assign` and
`label.remove`. Those names do not exist in Home Assistant, so users could not
build a working automation from the documented example (reported on HA
2026.7.4).

**Fix:** All references now use the actual service names,
`homeassistant.add_label_to_entity` and
`homeassistant.remove_label_from_entity`. Texts and a docstring only; no
behavior change.

**Files changed:**
- `README.md` - service names in the automation example (comment and call) and
  in the v2.3.0 highlight entry
- `custom_components/haghs/strings.json` + `translations/en.json` -
  `ignore_labels` data description (setup and options)
- `custom_components/haghs/coordinator.py` - `_is_ignored` docstring
- `ROADMAP.md` - multi-label ignore entry in the v2.3 completed list
